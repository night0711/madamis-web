# マダミス Web（夜活部の事件簿）

Discordの通話で遊ぶマーダーミステリー用の、**外部依存ゼロの静的サイト**です。HTML/CSS/JSだけで動き、そのままGitHub Pagesに置けます（`.nojekyll` あり）。CDN・外部フォント・解析タグ・広告は一切ありません。

```
index.html                 ポータル（scenarios/index.js の一覧を表示）
assets/                    共通エンジン（style.css / core.js / play.js / vote.js / handout.js / ending.js）
scenarios/index.js         ポータルに出すシナリオ一覧（公開情報だけ）
scenarios/<id>/
  scenario.js              公開データ（あらすじ・人物・ルール・進行表・手がかりカード）
  kv.svg                   キービジュアル（自作SVG）
  play.html / vote.html    共通ページ・投票ページ（中身は scenario.js から自動生成。基本は編集不要）
  h-<ランダム>.html         個別ハンドアウト（秘匿。中身はこのファイルに直接書く）
  host-<ランダム>.html      配布ページ（ハンドアウトURLの一覧とDM用コピー。ネタバレなし）
  e-<ランダム>.html         真相・エンディング（秘匿）
robots.txt                 検索エンジンに載せない（パスは書かない）
```

## 当日の遊び方（GMなし・全員プレイヤー）
いま入っている『ゆきのよるのコンビニ』（`scenarios/yuki-no-yoru/`）は **3人全員がプレイヤー、GMなし、約60分** です。
1. 主催（ひのまるさん）が配布ページ（`host-….html`）を開き、「部屋を作る」。出た共通ページのリンクを通話に貼る。DMは部屋を作ったあとにコピーする（ハンドアウトを開いた端末も同じ部屋に入る）。自分のハンドアウト以外は開かない。
2. 参加者は自分のスマホで共通ページを開く。フェーズ・タイマー・めくったカード・投票が揃う。ハンドアウトの中身は送られない。部屋を使わないときは、今まで通り共通ページを**画面共有**してもよい。
3. 進行のボタン（フェーズ、タイマー、カード、開票）は配布ページ。配布ページは開いたままにする。「いまやること」に従って進める。カードはホストが「めくる」。
4. 投票は各端末で送る（部屋を使っているとき）。ホストが配布ページで「開票する」。部屋なしのときは、今まで通り `vote.html` に票数を入れる。
5. 「本当に全員投票した？」に OK すると真相ページへ。1章ずつ「続きを開く」。投票を通らずに真相ページを開くと、まず「STOP」画面が出ます。

## 最後のひとこと推理
部屋を使っているとき、最終議論と投票の時間に、各端末で「容疑者」と「一行の理由」（60字まで）を出せます。出ている人数だけが見えて、文章はホストが配布ページで「一斉に公開」を押すまで出ません。出さなくても投票はそのまま進められます。使わないときは、押さずに開票して大丈夫です。部屋を使わないときは、今まで通り声で話します。送られるのは、その欄に打った短い文だけです。

## 今夜の振り返り
開票したあと、共通ページと、真相ページの最後の章のあとに「今夜の振り返り」が折りたたんで出ます。フェーズが始まった時間、めくったカード、票、公開したひとことを、その夜の流れとして残せます。真相の文章は入りません。開票前には出ません。

## サーバーなしで「公開状態」をそろえる仕組み
- **基本は画面共有**：ボタン係の画面が正。タイマーもカードもそのまま全員に見えます。
- **各自のスマホで見たい人向け**：手がかり欄の「共有リンクをコピー」でURL（`play.html#s=フェーズ番号.公開カードID`）を作り、Discordに貼る。開いた人の画面が同じフェーズ・同じ公開カードになります（その後の更新は再度リンクを貼るか、ボタン係の合図で各自「めくる」）。
- 状態は各ブラウザの localStorage に保存（再読み込みしても消えない）。メモ帳も端末内だけに保存され、誰にも送信されません。
- 効果音・環境音はWebAudioでその場で合成（音声ファイルなし）。初期OFF。`prefers-reduced-motion` の端末ではアニメーションを抑えます。

## 秘匿の考え方（大事）
- 共通ページ・ポータルからは、ハンドアウト／配布ページへ**リンクしていません**。URLを知っている人だけが開けます。
- 真相ページへのファイル名は `scenario.js` に base64 で入っていますが、これは「うっかり見えない」程度の目隠しで、**セキュリティではありません**。仲間内で遊ぶ前提の仕組みです。
- `scenario.js` は誰でも読めるので、**犯人・真相・HOの内容は絶対に書かない**こと。

## 新しいシナリオの追加方法
1. `scenarios/yuki-no-yoru/` をフォルダごとコピーして `scenarios/<新しいid>/` にする。
2. `scenario.js` を書き換える（`id` は新しいidに。`phases` の `min` が分、`unlock` がそのフェーズで光るカード）。
3. `kv.svg` を差し替える（SVGでも PNG/JPG でもOK。`scenario.js` の `kv` を合わせる）。
4. 秘匿ページのファイル名を**新しいランダム文字列**に変える。例：
   `node -e "console.log(require('crypto').randomBytes(9).toString('base64url'))"`
   - `h-<ランダム>.html` を人数分：中の `window.HANDOUT = {...}` を書き換え（`sid` は新しいid）。
   - `e-<ランダム>.html`：中の `window.ENDING = {...}` を書き換え。`choices` と `branches` のキーは `scenario.js` の人物 `id` と同じに。
   - `host-<ランダム>.html`：ハンドアウトのファイル名と名前を書き換え（配役以外の情報は書かない）。
5. 真相ページのファイル名を base64 にして `scenario.js` の `vote.endingRef` へ：
   `node -e "console.log(Buffer.from('e-XXXX.html').toString('base64'))"`
6. `scenarios/index.js` に1ブロック追加 → ポータルに並びます。
7. ローカル確認：`python3 -m http.server` で開いて、共通ページから秘匿ページへのリンクが無いことを確認。

※ 1作目は `/workspace/madamis/tools/build_yuki.py`（サイト外）が `scenario.js`・秘匿ページ・配布ページ・シナリオ原稿（`/workspace/madamis/yuki-no-yoru/*.md`）をまとめて生成します。直すときはスクリプトを直して、`/workspace/madamis` で `python3 tools/build_yuki.py` を再実行。2作目以降はこのスクリプトをコピーして使うのが楽です。

## エンジンのGMなし対応
- カードに `reader`（読み上げ担当）、人物に `player`（演じる人）、`vote.how`／`vote.lead`（投票の案内）、`mapTitle` を書けます。
- 投票ページは票数を隠さず表示（全員の前で入力する前提）。開票後の確認で `sessionStorage` に印を付け、真相ページは印がないと「STOP」画面を出します。

## 公開（GitHub Pages）
このフォルダの中身をリポジトリのルート（または `docs/`）に置いて Pages を有効にするだけ。リポジトリを**公開**にすると秘匿ページのファイル名もリポジトリ上で見えてしまうので、気になる場合はプライベートリポジトリ＋Pages（有料プランが必要な場合あり・未確認）か、別の置き場所を検討してください。
